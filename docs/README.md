# Flood Online Reporting Tool - Report Status
Administration and status reporting for the flood online reporting tool. Built for professional flood risk colleagues, tracking reports from both the public and lead authorities.

## Dependencies

To run the project with minimal modification, you will need:

- A web server capable of running .NET applications, such as IIS, Kestrel or Azure
- PostgreSQL 13+ with PostGIS extension

This uses Entity Framework. Postgres has been set up for this project, but with some modifications, any Entity Framework compatible provider should work. For a full list of providers, check the Entity Framework documentation.
